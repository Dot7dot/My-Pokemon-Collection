# My Pokémon Collection 我的寶可夢收藏庫

📱 **立即使用：<https://dot7dot.github.io/My-Pokemon-Collection/>**（建議用手機開啟，可以「加入主畫面」當 App 用）

一隻一隻收進圖鑑的個人寶可夢收藏庫，淡藍色和黃色配色，支援深色模式。純 HTML／CSS／JS，直接放在 GitHub Pages 上，不需要伺服器。

## 功能

- **圖鑑格子**：#0001～#1025 每一隻都是一個方塊，有寶可夢小圖、編號、名字，一路往下滑到 #1025
  - 依 **九個世代** 分區（關都、城都、豐緣、神奧、合眾、卡洛斯、阿羅拉、伽勒爾、帕底亞），每區標題會顯示收藏進度
  - 上方的世代按鈕可以直接跳到該世代；「只看已收藏」只列出有收藏的寶可夢
  - 有收藏的方塊會有金框和 ★，右上角的小圓點代表有哪幾種收藏
- **搜尋**：最上方輸入編號（`25`、`#025`）或名稱（繁中、簡中、英文、日文；平假名也可以），按 Enter 直接打開第一個結果
- **寶可夢頁面**：點方塊進入，有官方插圖（點一下看色違）、屬性、分類，左右滑動或按 ‹ › 換上一隻／下一隻
- **地區型態**：有阿羅拉、伽勒爾、洗翠、帕底亞樣子的寶可夢（共 54 種、57 個型態，例如阿羅拉九尾、洗翠火爆獸、帕底亞肯泰羅的三個種），
  頁面上會出現「🌏 地區型態」按鈕，切換後插圖、屬性和顏色都會跟著變（也可以再點插圖看該型態的色違）
  - 選好地區型態再新增模型或色違卡，卡片的外框顏色、屬性和預設名稱（例如「阿羅拉九尾」）都會用那個型態
  - 搜尋「阿羅拉」「洗翠」「galarian」等也能找到有該地區型態的寶可夢
- **四種收藏**，每一種都可以 **📷 拍照** 或 **🖼️ 上傳照片**，並加上 **介紹文字**：
  | 種類 | 內容 |
  | --- | --- |
  | 🧸 模型 | 公仔、絨毛娃娃、扭蛋、模型，做成自製收藏卡 |
  | 🃏 卡片 | 用 PTCG 標準尺寸拍下來，自動變成立體卡片 |
  | ✨ 色違 | 色違的截圖或照片，做成自製收藏卡 |
  | 🎨 畫圖 | 自己畫的或收到的圖 |
- 點收藏可以看大圖，左右滑動換下一張；右上角 ⋯ 可以編輯介紹、存到手機或刪除

### 模型、色違：自製收藏卡

模型和色違的收藏都是一張卡片：**最上面是名稱**、**上半部是照片**、**下半部是介紹**，
外框顏色跟著寶可夢的屬性（色違是彩虹銀色外框），中間有編號、名稱、屬性，底部是新增日期。

- 按 **＋新增** 會直接出現一張空白卡片，**照片框裡就是相機畫面**，對準收藏按快門就拍進卡片裡
  （🔄 切換前後鏡頭，🖼️ 改從相簿選）
- 拍好後可以在照片框裡拖曳、雙指縮放調整位置；不滿意就 📷 重拍
- **名稱和介紹直接點卡片上的字打字**，字越多會自動縮小；名稱預設是寶可夢的名字
- 選卡面效果後按 **完成**；之後在大卡右上角 ⋯ 可以再編輯，或 **存到手機**（存成整張卡片的圖）
- 看大卡時和下面的 PTCG 卡片一樣是立體的，可以拖曳、晃手機看反光、翻面

### 卡片：拍照變立體卡片

1. 在「卡片」按 **＋新增 → 拍卡片**，畫面上會有 **63 × 88 mm（PTCG 標準尺寸）** 的取景框，把卡片對準框線拍下來
   （手機支援的話右上角有 🔦 手電筒，拍閃卡時可以開關試試看哪個反光比較少）
2. 拍完會進入 **裁切**：拖曳移動、雙指縮放、⟳ 旋轉 90°、滑桿微調角度，讓卡片剛好填滿框線
   （選「上傳照片」也是用同一個裁切畫面）
3. 選卡面效果：**彩虹閃卡**、**金屬亮面**、**星塵閃**、**一般**，寫介紹後加入收藏
4. 收藏列表裡的小卡會自己輕輕晃動、反光流動；點開大卡：
   - **按住拖曳**：卡片跟著手指傾斜，光澤和閃卡效果跟著角度移動，陰影往反方向移
   - **晃手機看反光**：一打開大卡就會用陀螺儀，傾斜手機卡片就跟著轉、反光跟著跑（iPhone 第一次打開卡片時會詢問一次「動作與方向」權限，按允許即可；之後同一次使用不會再問）
   - **點兩下** 或按 **🔄 翻面** 看卡背

卡牌互動的概念參考 [CardKing](https://github.com/Dot7dot/CardKing) 的卡牌詳情（按住拖曳傾斜、反光跟著手指移動），
再加上卡片厚度、彈簧回正、閒置時微微晃動和陀螺儀。

## 資料存在哪裡？要備份！

- 所有收藏（照片和文字）都存在 **這台裝置瀏覽器的 IndexedDB** 裡，不會上傳到任何地方
- 換手機、換瀏覽器或清除網站資料，收藏就不見了，所以請定期到右上角 **⋯ → 📦 匯出備份**，會下載一個 `.zip`
  （裡面是 `collection.json` 和所有照片，用電腦也能直接解壓縮看）
- 到新裝置打開網站後按 **⋯ → 📥 匯入備份** 選那個 `.zip` 就能還原
- 第一次新增收藏時會請瀏覽器把資料設為「持續保存」，降低被系統自動清掉的機會

## 部署到 GitHub Pages

這個 repo 已經是可以直接上線的靜態網站：

1. 到 repo 的 **Settings → Pages**
2. **Source** 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**
3. 等一兩分鐘，網址是 `https://dot7dot.github.io/My-Pokemon-Collection/`

相機需要 HTTPS 才能在網頁裡打開；GitHub Pages 本來就是 HTTPS。
在本機測試可以在資料夾裡執行 `python3 -m http.server`，再開 `http://localhost:8000`（localhost 也可以用相機）。

## 檔案

```
index.html             頁面骨架
css/style.css          所有樣式（格子、寶可夢頁面、相機、裁切、立體卡片）
js/app.js              圖鑑格子、搜尋、寶可夢頁面、新增／觀看／編輯收藏、備份選單
js/dex.js              #0001～#1025 的名稱（繁中、英、日、簡中）、分類、屬性、世代
js/forms.js            地區型態（阿羅拉、伽勒爾、洗翠、帕底亞）的名稱與屬性
js/capture.js          PTCG 尺寸取景框相機、裁切
js/madecard.js         模型、色違的自製收藏卡（卡片編輯器、存成圖片）
js/card3d.js           立體卡片（傾斜、反光、閃卡效果、翻面、陀螺儀）
js/image.js            照片縮圖與壓縮
js/db.js               IndexedDB 存取
js/backup.js           匯出／匯入 .zip 備份（不需要外部函式庫）
js/ui.js               共用的小工具（彈出視窗、提示、選檔）
manifest.webmanifest   加入主畫面用
```

## 資料來源

寶可夢相關名稱與圖片的版權屬於 Nintendo／Creatures／GAME FREAK；這是個人收藏用的非官方專案。
